## Regra permanente: uso de skills

Antes de executar qualquer tarefa, verifique quais skills estão disponíveis e use automaticamente apenas as skills relevantes para o trabalho solicitado. Combine skills quando isso realmente melhorar o resultado. Não use todas sem necessidade.

- **Criação visual** (design, layout, UI): considere `frontend-design`.
- **Planejamento, desenvolvimento e correção** (bugs, features, debugging): considere as skills do pacote `superpowers`.
- **Testes no navegador** (responsividade, screenshots, verificação de erros de console): considere `playwright-cli`.

Antes de concluir qualquer alteração, faça as verificações adequadas (testes, revisão do resultado, etc.) antes de reportar a tarefa como concluída.
